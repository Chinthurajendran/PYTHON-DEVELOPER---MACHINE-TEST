🌐 Employee Management Frontend (React + Axios)

This is the React frontend for the Employee Management System.
It provides an interactive admin dashboard where users can log in, add employees, edit employee details, view all employees, and delete records.
The frontend communicates with the Django REST API backend.

🚀 Features

🔐 Admin Login using JWT authentication

👨‍💼 Add new employees (with photo upload)

✏️ Update employee details

🗑️ Delete employee records

📋 Employee listing with real-time updates

⚡ Toast notifications for success/error

🔄 Axios instance with token-based authorization

🎨 Fully responsive UI using modern React styling

🛠️ Tech Stack
Component	Technology
Framework	React 18 + Vite
API Handling	Axios
Routing	React Router
Styling	Tailwind CSS
Notifications	React Hot Toast
State	React Hooks
